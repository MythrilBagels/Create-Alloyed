# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- New decorative blocks - Bronze Column and Cut Bronze. Cut Bronze also comes in stair and slab variants. Textures by asof.
- Bronze casing, which can be used to encase Cogwheels, Belts, and Shafts. Textures by asof.

### Fixed

- Missing Steel Block, Steel Door, and Bronze Bell blocks after a Registrate update.

## [2.0.5] - 06-26-2025

### Fixed
- Fixed missing 1.21 item tags causing Steel Armour to not be enchantable (#142)

## [2.0.4] - 06-18-2025

### Fixed
- Fixed steel not requiring heat (#141)
- Smithing templates not duplicating (#140)

## [2.0.3] - 

### Fixed
- Changed mod loaded checks to use NeoForge's system.
- Added a fallback model for Steel Mesh Fence

## [2.0.2] - 05-26-2025

### Added
- Support for NeoForge 1.21.1

### Changed
- Added vanilla tool tags to Alloyed tools.

## [2.0.1] - 04-22-2025

### Changed
- Downgrade Forge requirement

### Fixed
- Fix Create Deco support

### Removed
- Legacy smithing recipes for non-tools.

## [2.0] - 2023-03-05
### Added
- Support for MC1.20.1, and Create 6.0+
- Proper Forge tags for various items

### Changed
- Steel Armour is now made with a new Smithing Template, crafted via Precision Crafting.
- Armour Trims can apply to Steel Armour
- Bronze Bells now produce particles like Note Blocks.

### Fixed
- Compatibility error with Create Encased (#114)
